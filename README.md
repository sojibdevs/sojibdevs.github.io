# Md. Sojib Miya: Portfolio

Senior .NET developer portfolio, published at https://sojibdevs.github.io

Built with Vite, React, TypeScript, Tailwind and shadcn/ui. All content lives in `src/data/data.json`.

## Run locally

```
npm install
npm run dev   # http://localhost:5173
```

## Deploy

Pushing to `main` builds the site and publishes it with GitHub Pages (`.github/workflows/deploy.yml`).
In the repo settings, Pages, set Source to "GitHub Actions".

## Update the CV

Replace `public/cv.pdf`.
